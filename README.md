### 👨‍💻 About Me

I am a **Full-Stack Web Developer** based in **Barishal, Bangladesh**, focused on building fast, responsive, and user-centric web applications. I enjoy solving real-world problems through clean architecture, type-safe code, and modern UI/UX design.

- 🔭 **Currently working on:** **HireLoop** — A modern full-stack job portal built with Next.js, TypeScript, Express.js, and MongoDB.
- 🚀 **Core Expertise:** End-to-end web development using Next.js (App Router), TypeScript, RESTful APIs, and secure authentication workflows.
- 🌱 **Focus Areas:** Scalable backend architecture, performance optimization, and clean component design.
- ⚡ **Workflow:** Writing clean ES6+ JavaScript/TypeScript, version control with Git/GitHub, and seamless cloud deployments on Vercel.
